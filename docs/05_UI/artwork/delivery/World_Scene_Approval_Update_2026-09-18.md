## Explicit presentation-direction change

The original W2 brief preferred austere fog and ruled out cloud castles; the accepted S07 image instead contains a gothic floating-city interpretation, a crimson moon and monumental architecture. This discrepancy is not concealed by declaring the old brief passed. The newer user decision accepts this game-oriented source direction. It is **not a literal Canon reconstruction** of Sefirah Castle and does not establish any new fact about its architecture, religious affiliation or ownership.

S08 expresses worldline observation through connected luminous orbs and branching paths within astronomical architecture. These are visual metaphors, not a new domain model or a claim about literal cosmology. S09 expresses containment through isolated display enclosures, restraints and watchful custodians. Its center object is environmental decoration, not an invented sixteenth Artifact.

The decision supersedes the earlier generation-only rejection preferences for these selected sources. It does not waive object Canon checks, text-free art, source integrity, interface contrast, crop safety, accessibility, Master provenance or G3–G5. It does not impose a crimson moon, cathedral or gold astrolabe on future Artifact object art.
