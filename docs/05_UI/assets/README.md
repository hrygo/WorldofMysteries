# UI 参考图与本机资产说明

> **状态**：本目录下的图片是**本机资产**，不入版本库。

## 目录

| 路径 | 内容 | 是否入库 |
|:---|:---|:---|
| `01_概念参考/` | 12 张高保真原型参考（8 个一级视图 + 灰雾之上 + 仪式魔法等） | ❌ `.gitignore` 排除 |
| `02_img_gen/` | 生成过程原图（按时间戳命名） | ❌ `.gitignore` 排除 |

这两条规则写在本仓库 [`.gitignore`](../../../.gitignore) 第 8 节，改动那里等于改动本说明。

## 为什么要留在项目目录内

- 这批图是设计基线的取证材料（[`UI_交互基线_v1.0.md`](../UI_交互基线_v1.0.md) 第 13 节逐条批准），
  需要能随时对照复核，因此**不能只存在于临时目录或仓库之外**；
- 同时它们体积在 50 MB 量级、且属于设计过程资料而非运行时资产，不适合进入 Git 历史
  （判据见 [`../artwork/Asset_Storage_Policy_v1.0.md`](../artwork/Asset_Storage_Policy_v1.0.md)）。

## 克隆仓库后会看到什么

新克隆的仓库里本目录只有这份 README，`01_概念参考/` 与 `02_img_gen/` 为空：

- 文档（`docs/README.md`、`docs/ASSET_INDEX.md`、`docs/PROJECT_STATE.json`）登记的是这批图的
  **路径与用途索引**，不是可下载的二进制；引用不可解析属于预期行为，不是链接写错；
- 需要图片本体时，从原生产机拷贝整个 `docs/05_UI/assets/` 目录即可，无需调整任何配置。

## 派生关系

本目录只存放设计参考与生成原图。运行时资产（`Assets.xcassets`）来自
[`../artwork/`](../artwork/) 的母版流水线，两者不可互相替代：
参考图约束视觉方向，运行时资产才是 App 实际加载的副本。
