# 《诡秘世界》产品体验与交互基线 v1.0

> **状态**：UX 规范基线  
> **首发平台**：macOS 26+，Apple Silicon arm64  
> **主要交互媒介**：世界观测 + 语音介入 + 沉浸式故事


## 1. 世界感

应用不是功能中心，而是一个持续存在的个人世界。用户打开应用首先“回到世界”，而不是“创建任务”或“生成故事”。

世界首页应表现为世界观测台：

- 中央是当前世界视窗，而非 KPI Dashboard。
- 世界重要事件自然浮现，而不是瀑布流。
- 人物是世界中的存在点，而不是头像列表。
- 用户首先观看、感受、产生好奇，再介入。
- 世界关闭应用后停止演绎，但状态持续存在。

## 2. 用户角色

用户不是固定玩家化身，而是：

- 观察者
- 命运顾问
- 世界见证者

在故事关键节点给人物建议，但建议不是命令：

```text
Player Advice ≠ Command
Advice = influence, not direct control
```

人物根据自身知识、人格、价值、关系、能力与风险决定如何执行，可 full / partial / reinterpret / reject。

## 3. 语音交互

语音是命运介入和沉浸故事阶段的主要交互方式。

### 世界首页

低介入：以观看为主。用户可自然问“刚才那个人是谁？”、“这件事为什么值得注意？”，系统以克制旁白回答，不弹聊天框。

### 命运介入

语音成为主要输入。系统通过世界和人物的语言呈现局势，用户直接说出建议。

### Story Player

界面尽量退场。主要由环境声、人物、旁白和语音构成；命运节点出现时建议方向轻量浮现，用户可直接说出 Advice，不受建议方向限制。

语音反馈不采用强科技麦克风视觉，而采用克制的“世界正在聆听”反馈，例如黄铜色命运环、呼吸式波纹、低亮神秘学符号。

## 4. 卡牌收藏与世界结合

卡牌不是抽卡养成玩法，而是：

> 世界入口 + 用户认知凭证 + 人物历史载体

### 原著人物卡

进入已存在人物的视角，继承 Canon 身份、人格、知识、关系、阶段能力与历史。

### 序列卡

代表序列原型。选择后可生成符合时代、地域、阶层、背景、能力和限制的原创人物。

### 卡牌显影

人物可能先存在于世界，用户尚未完全认识他。卡牌随探索逐渐显影：

```text
未知轮廓 → 姓名 → 身份 → 途径/序列 → 关系 → 经历 → 世界历史
```

收藏因此是“认识世界”的过程。

### NPC 晋升

Minor NPC → Recurring NPC → Persistent Character → Card

重要 NPC 可随着出现次数、关系、秘密重要性、世界影响与用户关注逐渐升格为持久角色，最终获得卡牌。

## 5. 主要页面闭环

```text
世界首页
  ↓
人物 / 事件 / 地点
  ↓
命运介入
  ↓
Story Player
  ↓
Story Book
  ↓
Memory / World Event / Character Update
  ↓
世界首页（世界已改变）
```

### 世界首页

目标：让用户感觉“世界一直在，只是我现在看见了”。

关键元素：

- 当前世界视窗
- 世界脉搏 / 重要 Observation
- 命运回响：过去介入事件产生的新后果
- 人物存在点
- 世界时间与地点感
- 极低干扰语音入口

### 人物存在档案

不是属性表，而是一个人的“存在档案”：

- 当前状态
- 现在知道什么
- 当前目标
- 关系
- 重大经历
- 正在改变他的事情
- Voice Persona
- Canon 与“你的世界”经历分层

### 命运介入页

展示当前局势，但严格避免上帝视角泄露：

- 人物所知
- 世界可观察信息
- 异常征兆
- 当前目标与压力
- 语音建议入口

### Story Player

全屏沉浸场景，UI 退后，仅在关键节点显现：

- 场景
- 人物对白
- 必要字幕
- 环境声
- 世界正在聆听状态
- 命运节点建议方向 / 自由 Advice

### Story Book

不是任务结算，而是私人史书：

- 封面与章节
- 命运路径
- 已揭露秘密
- 关键人物
- 世界影响
- 完整有声故事

### 世界线

只在真正的 Major Divergence 之后强调，表现“历史发生偏移”，不做 Git 分支图式工具界面。

### 地点探索

地点也具有记忆：已发现地点、历史事件、人物、秘密、世界状态变化。

### 人物关系网络

关系不是单一数值；包括信任、敬畏、敌意、债务、共同秘密、冲突、最后相遇与支持这些关系的具体记忆。
