# 价值目标与验收基准（Voice Foundry）

## 一、价值目标

建设可持续供给、可审听验收、可恢复运行的角色音色体系，使旁白与人物拥有稳定、可区分、可追溯的声音身份。系统贯通需求授权、目录复用、候选生成、人工选优、跨文本复验、发布和持久绑定，减少人工配置及重复铸造。语音准备与剧情推进独立：缺货、服务故障或待审听时，文字正常交付，已提交世界事实保持不变。方案支持后续扩充人物与替换服务商，同时保持声音连续性、知识隔离和历史音轨完整。

## 二、验收标准

| # | 结果承诺 | 必须提供的证据 |
|:--|:---|:---|
| 1 | **身份稳定**：旁白及首批 3—5 名主要人物完成真实听审；按身份逐段配音，不共用全局默认声线，不自动换声，显式替换仅影响未来片段。 | 每个身份的真实试听记录、绑定修订与逐段交付记录；换声前后片段对照 |
| 2 | **质量闭环**：参考确认、跨文本复验、人工身份与自然度评审、发布证据完整；证据绑定声音和模型版本，缺失、失效或撤销时拒绝正式合成。 | 合格证据及错误范围拒绝断言；机器结果不代签人工结论的证据 |
| 3 | **体验连续**：缺声片段显示字幕和明确状态，其他片段正常交付；音色就绪后不自动重播已读内容。 | 缺货、多角色、旁白与稍后就绪场景的端到端记录 |
| 4 | **可靠恢复**：重启、超时、重复请求、并发绑定及取消均不重复铸造、不覆盖有效绑定、不重复提交剧情。 | 故障注入记录、调用次数、数据库状态与领域提交不重复的联合断言 |
| 5 | **边界安全**：隐藏身份与未来剧情不进入提示、试听或日志；表现数据更新不改变世界事实，历史音轨保持可追溯。 | 授权反例、世界 revision 不变证明、历史 take/track 引用核验 |
| 6 | **交付可信**：契约、迁移、客户端与测试同步交付，完整门禁通过；提供真实服务联调、冷启动严格合成及人工听审证据，明确未验收项，模拟测试不替代真实验收。 | `FULL_P0` 实际结果、各包 Work Receipt、真实服务身份与验收记录、未验收清单 |

## 三、交付边界

- 本任务交付需求授权、候选铸造、人工选优与听审、发布、持久绑定和逐段消费闭环。
- 缺货或待审听只影响语音表达，不阻塞领域提交、文字交付和世界事实。
- 机器评分、mock、fake、单候选成功和 provider HTTP 成功都不能替代真实人工听审。
- SpeechRail 及其他服务由各自团队维护；跨仓只消费版本化契约，不共享代码、虚拟环境或本地路径。
- 模拟测试用于证明状态机、授权、幂等与拒绝行为；真实声学质量、自然度和同场区分度必须单独记录。
