# 廷根原创角色与音色铸造输入

> 状态：**待试听听审**。本文是 Voice Foundry（ADR-005）验收标准 1 的输入清单，
> 不是已完成的铸造记录。真实铸造与听审受阻于
> [SpeechRail#116](https://github.com/hrygo/SpeechRail/issues/116)（VoiceDesign 通道
> 持续 503 `tts_transport_failed`），该 issue 修复后方可执行本文第 5 节的听审流程。

## 1. 定位与边界

本批角色是**用户世界原创**（`kind: original`、`canon_anchor: null`），只存在于
`user_world`，**永不回写 canon**（不变量 10）。他们都是廷根的普通市民，
`pathway_id` 与 `sequence` 皆为 `null`，不涉及任何途径或序列，与原著无冲突。

### 世界观纪律（编写本类内容时的硬约束）

1. **姓名取"廷根式"虚构名**，对齐原著既有人物命名（克莱恩·莫蕾蒂、邓恩·史密斯、
   伦纳德·克莱恩、本森、瑞尔·约翰逊、奥黛丽·霍尔），不贴任何现实民族标签。
   **公开名一律中文**（2026-10-01 人类架构师裁决）：不出现英文名或外语音译名，
   `Jonathan` 一类写法作废——名字既要能念，也要听起来属于此地。
2. **出身只写"廷根本地"或在虚构地名间流动**，不写现实国家、民族、语族。
3. **地名只用诡秘世界虚构地名**（廷根、贝克兰德、因蒂斯、费沙），不出现现实城市。
4. `occupation` 使用中性职业词，不带国别修饰。

> 修订记录：初版曾把机械师写成"德国裔移民"并使用德语姓氏，属于把现实欧洲史
> 误植入架空世界的范畴错误，已按上述纪律修正为廷根本地机修世家。

## 2. 选角逻辑

覆盖廷根的四个阶层——工业蓝领、专业中产、新闻舆论、执法力量——保证五路声音
在音高 × 语速 × 质感三轴上全部拉开，满足验收标准 1「不共用声线、可区分」。
四人各挂一条叙事钩子，都指向廷根不该存在的"意外"，可驱动调查向玩法，
同时不妨碍 `golden_001` 主线。

## 3. 角色档案

### 3.1 旁白（叙事主声道，非角色）

廷根的讲述者：冷静、略带距离感，知道得比说出来的多。由它串起雾、蒸汽与煤气灯，
它从不评判，只呈现。**必须是独立声音，不与任何角色共用**（验收标准 1）。

| 维度 | 设定 |
|---|---|
| 性别/年龄感 | 不指定性别，中性，30–40 岁成熟感 |
| 音色质地 | 温润，带一点旧书卷气 |
| 音高 | 中音 |
| 语速 | 偏慢，留白从容 |
| 口音 | 标准中文，无口音 |
| 情绪基调 | 沉静、带悬念的引导感，不夸张 |
| 避免 | 播音腔、激昂、甜腻 |

- 参考台词：「煤气灯在雾气里晕开，蒸汽管道的低鸣像是这座城市尚未醒来的呼吸。」
- 复验台词：「钟楼敲过九下，潮水顺着堤岸往上爬，把昨夜没捞干净的脚印又抹了一遍。」

### 3.2 维克多·奥斯本（Victor Osborn）—— 机械师 / 工头

**为什么理应存在**：廷根靠蒸汽与纺织厂立市，不可能没有管机器的人；原著的工业
只写机器不写人，给了齿轮却没给一个守齿轮的师傅。

**肖像**：52 岁，廷根黑石区生人，父亲当年在码头修起重机，他十四岁进厂当学徒，
一路熬到工头。宽肩，花白络腮胡，手掌被机油浸得发亮，常年被轰鸣震得听力发闷。
带了七八个学徒，视如己出。有一条根深蒂固的工人迷信——"夜里别对锅炉说话"。

**想要 / 隐瞒**：想让一个学徒的女儿进厂医的账房，别再进车间；最近他发现 3 号
锅炉的排气节奏"不对"，像有人在夜里动过什么，但不敢深查，怕丢饭碗。他知道一条
不该知道的：三个月前那次"意外"死者被裁定为误判，尸体却在入殓前不见了。

| 维度 | 设定 |
|---|---|
| 性别/年龄感 | 男，50 岁上下 |
| 音色质地 | 粗粝、沙哑，常年被机器声磨过 |
| 音高 | 低 |
| 语速 | 慢而顿，像在掂量每个词 |
| 口音 | 廷根本地口音，咬字重 |
| 情绪基调 | 务实、不耐烦，对上层略带怨气 |
| 避免 | 文雅、清晰的播音腔 |

- 参考台词：「机器老了才最要紧，人老了还能修，机器散了可没人赔得起。」
- 复验台词：「我修过贝克兰德运来的新锅炉，都比不上咱们这台老伙计懂事——它只是饿，不是坏。」

### 3.3 艾达·芬奇（Ida Finch）—— 私人医生

**为什么理应存在**：廷根有街区诊所，也有替穷人赊账的医生；原著的医生多是
"某位大夫"的功能性背景。三十多岁的女医生在廷根并非不可能，寡居的妇科与
全科大夫并不罕见。

**肖像**：37 岁，寡妇，丈夫死于五年前的意外。诊所不大但收拾得一丝不乱，指节
常有墨渍，身上总带着石炭酸的味道。话不多，手很稳。铁律：病人的秘密带进坟墓。

**想要 / 隐瞒**：想把诊所改成一间收治女病人和穷人的小病房，缺钱缺人；去年她替
一个从工厂送来的女孩处理过"不该有的伤"，签了死亡证明，却从未告诉家属真正的
死因——她握着这座城市某个体面的污点。

| 维度 | 设定 |
|---|---|
| 性别/年龄感 | 女，35 岁上下 |
| 音色质地 | 清亮、稳定，干净 |
| 音高 | 中偏高 |
| 语速 | 中等偏快但条理清楚 |
| 口音 | 标准，略带受过教育的克制感 |
| 情绪基调 | 冷静专业，带着克制的关切 |
| 避免 | 尖锐、冷漠到刻薄、嗲 |

- 参考台词：「把伤口按住别松手，麻药退下去之前，人不能睡过去。」
- 复验台词：「我救得了外伤，救不了你瞒下来的事——把实话告诉我，我才能决定先救哪一头。」

### 3.4 塞缪尔·克拉克（Samuel Clark）—— 报社记者

**为什么理应存在**：廷根有两份报纸，报社会拿消息换钱；原著里的线人多是匿名的，
没有一个"追着独家跑"的记者。有名有姓的记者，能给玩家一个能主动打交道的消息入口。

**肖像**：27 岁，负债边缘，西装永远差一截熨斗，眼睛亮得过分。嘴比脑子快半拍，
却总能在关键处嗅到别人忽略的味道。胆子不小，一到真场面又会发怵。

**想要 / 隐瞒**：想靠一条独家翻身；半个月前一个线人给了他关于廷根大屠杀后续的
碎片，他没完全听懂却不敢放，也没敢深挖——攥着一个自己都不明白的真相，
这既是他最大的本钱也是他最深的危险。

| 维度 | 设定 |
|---|---|
| 性别/年龄感 | 男，26 岁上下 |
| 音色质地 | 清亮偏薄，语速带动，略急促 |
| 音高 | 中高 |
| 语速 | 快，跳跃，藏不住兴奋 |
| 口音 | 标准，读过书但爱装老练 |
| 情绪基调 | 机敏、好追问、略带油滑的幽默 |
| 避免 | 低沉、慢条斯理、老气 |

- 参考台词：「先生，一条独家只要够快，印刷厂和您的名字就会一起出现在明早的头版上。」
- 复验台词：「我这条命不值钱，可这条消息值——您要是慢了，明早它就是别人署的名。」

### 3.5 乔治·哈特（George Hart）—— 巡官

**为什么理应存在**：廷根的秩序靠警察，原著的官方力量多是背景或无名。名侦探
身边的"一个扛事的巡官"，能给玩家一个在规则内周旋、又不完全可信的执法视角。

**肖像**：42 岁，当差二十年，见过太多"意外"。方正，少言，制服熨得笔挺。办案
讲程序——因为在这座城市里，程序是唯一还没烂掉的东西。

**想要 / 隐瞒**：想在退休前把手上一个"工厂事故案"办成铁案；私下发现近半年所有
涉"煤气/机械"的死亡都被悄悄改过分类，而改分类的不是他上司就是他上司的上司——
他在用程序做一件程序本身已经被污染的事。

| 维度 | 设定 |
|---|---|
| 性别/年龄感 | 男，40 岁上下 |
| 音色质地 | 厚实，有胸腔共鸣 |
| 音高 | 中低 |
| 语速 | 中速，短句，命令感 |
| 口音 | 标准，硬朗 |
| 情绪基调 | 公事公办，带一点不耐，偶露人情味 |
| 避免 | 阴阳怪气、慢吞吞、暴怒 |

- 参考台词：「封锁这条街，没有我的章子，谁也别想抬走一具尸体。」
- 复验台词：「按规矩，一份改过分类的报告要么被驳回，要么把签字的人一起送进去——你选哪条？」

## 5. 首批听审结果（2026-09-30）

**性质**：以下是 **preview 阶段**音频，用生产适配器
（`SpeechRailVoiceFoundryAdapter`）从真实 SpeechRail 3.4.0 VoiceDesign 通道
铸出，5 段均已校验为有效 PCM（24 kHz 单声道，时长 4.2–8.8 s）。

preview 音频用于判断**声线方向对不对**，不是验收标准 1 的正式听审。正式听审
标的是 asset 音频（参考段 + 跨文本复验段两段），须在 create→confirm→validate
之后才存在。两步走是为避免为错方向的音色付完整铸造成本。

| 身份 | preview 听审 | 裁决 |
|---|---|---|
| 旁白 | 已试听 | 未提异议，方向保留 |
| 维克多·奥斯本 | 已试听 | **需更换**，已重铸并复审通过 |
| 艾达·芬奇 | 已试听 | 未提异议，方向保留 |
| 塞缪尔·克拉克 | 已试听 | 未提异议，方向保留 |
| 乔治·哈特 | 已试听 | 未提异议，方向保留 |

「未提异议」不等于「已签署」：正式听审仍需在 asset 音频上逐人签署身份一致性与
自然度，机器指标不可替代（见第 6 节第 6 步）。

### 5.1 维克多：为什么换，以及换成了什么

第一版按第 3.2 节的画像直译（五十岁、粗粝沙哑、务实**不耐烦**、对上层略带
**怨气**），听审认为不像一个机械师该有的声音。按「太老／太糙／情绪太满」三条
轴各铸一版，台词与参考文本固定不变，只有配方在变，使听审比较的是声音而非词语：

| 变体 | 改动轴 | 结果 |
|---|---|---|
| A | 压低年龄、去掉沙哑，金属感改由职业给出 | 未采用 |
| B | **保留五十岁的粗粝沙哑，去掉不耐烦与怨气** | **采用** |
| C | 去掉年龄强调，中性化、克制内敛的手艺人 | 未采用 |

采用版本的铸造输入：

> 一位五十岁上下的男性。音色粗粝、沙哑，常年被机器声磨过。低音。语速慢而顿。
> 情绪沉稳、可靠，像是修过很多坏机器之后不再着急的人。不要不耐烦，不要怨气，
> 不要对任何人抱怨。

这意味着第 3.2 节表格里的「情绪基调：务实、不耐烦，对上层略带怨气」应读作
**人物处境**而非**音色要求**：底层技工对这座城市的怨气是人物内核，但把它写进
声线会让声音变成一个抱怨的老人，而不是一个仍在干活的手艺人。两者在文字档案里
都保留，在铸造输入里只保留后者。

`seed=34`（A 为 21、C 为 55）。seed 与描述共同决定候选；换 seed 即换样本，
不作为身份的一部分记录。

### 5.2 盲听听审实测（2026-10-01）

**标的**：5 个已发布资产的同句台词音频（`scratch/voice-audition/盲听/A.mp3` …
`E.mp3`，该目录为 gitignored 听审素材，不入库），台词统一为
「雨从凌晨开始下，一直没有停的意思。」——固定同一句是为了让比较落在音色而非词语上。

**方法（重要限定）**：听审人**先**听了带身份标注的同名音频建立印象，**再**做识别，
因此本轮是**再认测试（recognition）**，不是严格盲测。它能证明「五人两两不混淆」，
不能证明「初次聆听即可对上人物名」。后者需未接触过素材的第三方，或换一批台词重测。

| 盲听标号 | 听审人判定 | 实际资产 | 结果 |
|---|---|---|---|
| A | 乔治·哈特 | `george-hart` | ✓ |
| B | 艾达·芬奇 | `ida-finch` | ✓ |
| C | 旁白 | `narrator` | ✓ |
| D | 塞缪尔·克拉克 | `samuel-clark` | ✓ |
| E | 维克多·奥斯本 | `victor-osborn` | ✓ |

5/5 全对，且听审人明确表示**没有听出任何两段相似**——验收标准 1 的
「不共用声线、无混淆」成立。

**遗留缺陷（听审人原话）**：「没有特别像的，但是区分度又不是那么明显。」
即：可区分但辨识余量小。原文第 4 节的「三轴全拉开」在音高 × 语速 × 质感上
偏乐观。**本轮未采集逐轴归因数据**，因此无法断言五条的分离主要由哪一轴承担；
后续重测须同时记录「混淆对」与「最难分辨对」，再决定加密哪一轴。

**裁决**：本轮**有条件通过**。五个声线均可绑定为正式渲染声线，不需重铸；
但「区分度」记为已知质量债，后续新增角色时须加大三轴间距（尤其是质感轴），
并把本节作为对照基线——若新增声线在同句盲听中出现任一混淆，即为不合格。

## 6. 待执行：真实铸造与听审流程

前置条件：[SpeechRail#116](https://github.com/hrygo/SpeechRail/issues/116) 已修复，
`POST /v1/voices/previews` 不再返回 503。

对第 3 节每个身份执行：

1. **preview**：以上表 `voice_description` 作为 `voice_description`、
   `reference_text` 作为参考文本，生成候选并**下载音频**。
2. **create / confirm**：铸成候选并绑定参考文本。
3. **read_asset**（参考音频）：确认能在该修订号下读到音频——这一步是 VF-25 修复的
   目标，也是听审的前提。
4. **validate**：以 `复验台词` 做跨文本复验，防止音色只对单句调好。
5. **read_asset**（复验音频）：确认跨文本音频可读。
6. **人工听审**：由人分别签署身份一致性与自然度（`pass`）。**机器指标不可替代。**
7. **publish**：发布并绑定证据（证据须含 `voice_revision`、身份一致性、模型制品与
   目录修订四 pin）。

任一身份未通过听审，则**不得**绑定为正式渲染声线；缺声片段按验收标准 3 走字幕
与明确状态降级，不阻塞文字交付。

## 7. 运行时落库（听审通过后）

听审通过的角色连同 voice 绑定写入 `user_world`，各自 `canon_anchor: null`。
角色状态按 `contracts/schemas/character.schema.json` 落库；本文第 3 节的档案已
按该 schema 组织，可在试听过审后直接转为 fixture。当前**不**落 fixture——
没有任何代码消费未过听的角色数据，先过听审再落库。
