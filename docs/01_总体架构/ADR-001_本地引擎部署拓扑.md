# ADR-001：本地引擎部署拓扑

> **决策**：采用 **Embedded Local Engine Service**。  
> **状态**：Accepted  

## Context

首发产品为 macOS 26+ / Apple Silicon arm64 的单真实用户持久世界。UI 使用 SwiftUI；AI Runtime 使用 Python 3.14.7（CPython standard GIL build） 与 AgentScope。Domain Engine 需要独立崩溃恢复、SQLite 单写入者和可替换模型能力。

## Decision

```text
Mac
├─ MysteriousWorld.app
│   └─ SwiftUI / Audio / macOS integration
│
└─ Embedded Local Engine Service
    ├─ bundled Python 3.14.7 runtime
    ├─ Domain Engines
    ├─ AgentScope
    ├─ SQLite
    └─ model / speech adapters
```

约束：

1. Engine 随 App 分发。
2. Engine 与 App 位于同一设备。
3. Engine 独立进程运行。
4. Engine 生命周期由 App 管理。
5. Domain Database 仅由 Engine 打开和写入。
6. App 通过 typed local protocol 访问 Domain API。
7. Engine 默认不作为登录项或系统常驻 daemon。
8. App 退出后世界停止演绎；Engine 完成 checkpoint/flush 后退出。
9. Engine 崩溃不导致 App 进程崩溃；重启后按事务状态恢复。
10. 用户无需单独安装 Python。

## IPC Profile

MVP 控制面使用本地 Unix Domain Socket 和版本化消息协议。

- Request/Response：typed JSON message；
- Streaming：event frames；
- 大型 Audio/Image binary 不以内嵌 base64 通过控制通道传输，使用受控 asset reference；
- App 与 Engine 在 handshake 时交换 `protocol_version`、`engine_version`、`schema_version`。

IPC Domain Contract 不暴露 AgentScope 类型。

## Sandbox / Distribution

直接 child-process 形态继承父 App sandbox。所有 bundled executable 均纳入签名与 entitlement 验证。

如果发行形态需要不同 entitlement 或更强 privilege separation，Engine supervisor 切换为 XPC/helper 封装；Domain Protocol 与 Engine Domain Code 不变化。

## Rejected

- Swift 与 Python 同进程嵌入；
- MVP 强制远程 Engine；
- 用户自行安装/启动 Python 服务；
- Engine 永久在线后台模拟世界；
- SwiftUI 直接访问 `world.db`。

## Consequences

优势：

- AI Runtime 和 UI 故障隔离；
- Python/AgentScope 依赖独立升级；
- 数据写入集中；
- 可实现 Engine 单元测试和 headless Golden Scenario；
- 未来 RemoteEngineClient 可替换 LocalEngineClient。

代价：

- 需要本地 IPC；
- 需要 bundled runtime 的 codesign/notarization/sandbox 验证；
- 需要 Engine health check 与 lifecycle supervisor。
