# 《诡秘世界》总体架构基线 v1.0

> **状态**：系统设计基线  
> **架构风格**：Local-first、Domain-first、Typed Contracts、Event-aware、AI-bounded  
> **首发部署**：单设备、单真实用户、App-managed local engine  

---

## 1. 架构目标

系统必须同时满足：

- Persistent World：世界状态跨会话持续存在；
- Character Continuity：人物身份、知识、关系与记忆连续；
- Canon Safety：Canon、能力、知识和时间边界可验证；
- Voice-first Interaction：语音是命运介入和 Story Player 的主要输入；
- AI Replaceability：模型与 Agent 框架可替换；
- Crash Safety：已提交事实可恢复，Narrative/TTS 失败不反向改变状态；
- Local-first Privacy：用户世界默认保存在本机。

## 3. Domain 权限

### Lore Engine

拥有 Canon Fact、Canon Rule、Evidence、Timeline、Pathway/Sequence/Ability、Spoiler metadata。

### World Engine

拥有 Worldline、WorldEvent、世界时间、地点/组织/谜团状态、Visibility/Observation。

### Character Engine

拥有 Character Core、Character State、Goals、Values、Decision、Capability 使用意图、Relationship 语义。

### Memory & Knowledge Engine

拥有 Character Knowledge、Belief、Memory、记忆蒸馏、知识传播、检索授权前置规则。

### Story Engine

拥有 StorySeed、StorySession、StoryState、Commitment、Clue/Secret、BeatPlan、Closure、Episode Draft。

### Audio / Voice Engine

拥有 VoicePersona、PerformancePlan、AudioScene/AudioTimeline 语义与音频资产生命周期；麦克风采集、VAD/ASR 输入适配和实际播放设备由 SwiftUI / Media Runtime 持有。

      ↓

      ↓
BeatPlan
      ↓

      ↓
NarrativeBlock
      ↓

      ↓

```

### Commit Boundary

`COMMIT` 之前决定事实；`COMMIT` 之后决定表达。

- Narrative regeneration 不改变 StateDelta。
- TTS regeneration 不改变 NarrativeBlock。
- UI animation 不改变 Domain State。
- Agent interruption 在 Commit 后只能停止表达，不能回滚事实。

  audio / images / exports
```

## 7. Context 与 Memory 双层边界

### Domain Context

回答：

> 当前调用者有资格知道什么？

由 Context Compiler、Knowledge、Visibility、Spoiler、Worldline、Time 决定。

### AgentScope Context

回答：

> 已授权内容如何压缩、装载并适配模型上下文？

两者不得合并。

### Domain Memory

人物真正记住的经历，持久化于 `world.db`。

### Runtime Memory

AgentScope 执行中的消息、临时状态、压缩摘要。它不构成人物历史。

---

## 8. 事件与状态

系统不采用“纯 Event Store 每次全量 replay”作为在线查询方式。

`world.db` 同时保存：

- append-only Domain Events；
- transactionally maintained current projections；
-必要快照。

所有属于同一次 Domain Commit 的 Event、Projection、Revision、Outbox 在一个 `world.db` transaction 中完成。

---

## 9. Graph 定位

领域关系事实存在于专用 Domain Table：

- relationships；
- organization_memberships；
- character_knowledge；
- character_beliefs；
- memory_links；
- event causality；
- clue / secret links。

跨域统一 Graph 是派生 Projection，不成为第二事实源。

---

## 10. 可替换边界

以下组件通过 Adapter/Protocol 隔离：

- AgentScope；
- Cloud LLM；
- Local LLM；
- Embedding；
- Vector Index；
- ASR；
- TTS；
- IPC transport；
- future remote engine。

Domain Contract 不依赖具体 Provider 类型。

---

## 11. 非目标

首发版本不实现：

- 多真实用户共享 World State；
- 多设备并发写；
- 远程数据库作为必要运行条件；
- 全量 NPC 后台 Agent 模拟；
- Agent-to-Agent 自由聊天；
- 模型直接 SQL；
- Narration 驱动状态写入；
- Vector Search 绕过 Knowledge/Visibility Gate。

---

## 12. 架构验收不变量

任何实现均必须保持：

```text
Canon != User World
Truth != Knowledge
Knowledge != Belief
Knowledge != Memory
Advice != Command
Proposal != Commit
State != Narrative
Domain Memory != Agent Runtime Memory
World Time != Real Time
Authoritative Data != Retrieval Index
```
