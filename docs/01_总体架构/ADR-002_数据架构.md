# ADR-002：SQLite-centered 数据架构

> **决策**：采用 **SQLite-centered Local Multi-model Persistence & Retrieval Architecture**。  
> **状态**：Accepted  

## Decision

```text
canon.db       immutable Canon truth
world.db       authoritative mutable user world
retrieval.db   rebuildable search projection
runtime.db     non-domain runtime trace / diagnostics
assets/        binary media assets
```

### world.db

承载：

- World / Worldline；
- Domain Events；
- Current State；
- Character / Relationship；
- Knowledge / Belief / Memory；
- Story Session / Turn / Episode；
- Revision / Idempotency；
- Transactional Outbox。

### retrieval.db

承载可重建 Projection：

- FTS5；
- Embeddings；
- Vector index；
- Cross-domain graph projection；
- ranking metadata；
- projection checkpoints。

### Consistency

`world.db` 是强事务事实层。`retrieval.db` 使用 Transactional Outbox 异步更新。

禁止依赖 WAL 模式下多个 attached database 的跨文件 crash-atomic commit。

### Retrieval

```text
Authorization
→ hard structured filters
→ structured / graph / FTS / vector candidates
→ rank fusion
→ domain rerank
→ context packing
```

### Vector

Vector implementation 通过 `VectorIndexProvider` 抽象。

- MVP 首先使用 exact search；
- SQLite Vec1 是本地 ANN 候选实现；
- Vec1 不成为 Domain dependency；
- Vector index 必须可删除重建。

### Graph

Domain relation truth 保存在专用 Domain Table。统一 Graph 是可重建跨域 Projection。

## Rejected

- Neo4j 作为第二事实源；
- PostgreSQL 本地服务作为首发必要依赖；
- 独立 Vector DB 作为 MVP 必需组件；
- Kùzu 作为长期基础依赖；
- DuckDB 作为事务主库；
- Agent memory 作为人物 Memory Truth。

## Upgrade Triggers

重新评估专业数据库只由可测量条件触发：

- 多设备/多进程并发写成为产品需求；
- cross-domain graph 查询成为 p95 关键瓶颈；
- 向量规模与 ANN SLA 超出本地实现能力；
- 产品进入持久 Cloud / Multi-user 模式。
